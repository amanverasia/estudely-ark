How to get it

by torrent, or from a friend

  1. Install a torrent program, for example qBittorrent (free).
  2. Open the magnet link or the torrent file above.
  3. Choose the folders you want. Always keep Shared-Readers and the files at the top: README, START-HERE, Start-Library, Verify, MANIFEST and KEYS.
  4. When it finishes, leave the torrent program open so others can download from you.

Already have a copy on a USB drive? Copying it works the same way. One computer can also share the library with a whole room over local Wi-Fi.

How to use it

double-click and read

  • Windows: double-click Start-Library.bat
  • Mac: double-click Start-Library.command. If the Mac refuses, open Terminal in the folder and run sh Start-Library.sh
  • Linux: run sh Start-Library.sh

Your browser opens the library's home page, and nothing goes to the internet. README.txt covers Android phones, Wi-Fi sharing and the AI assistant.

On an Android phone

the Estudely Ark app · free · Android 8 or newer

The app downloads the parts you choose straight to your phone, checks them against the signed file list, and opens them offline: books with search, PDFs and the map of India with place search. Downloads wait for Wi-Fi unless you allow mobile data.
