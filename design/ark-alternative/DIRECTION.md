# Option B: Bookshelf

An alternative to the shortlisted Field Library direction. This keeps Ark's existing features and sample download state, with a different emphasis.

## Plan

Palette: chalk #F7F8FC, ink #202B43, blue #3855B6, soft blue #E8EDFC, lavender #E8E0F0, honey #F4E4BC.

Typography: Avenir Next / system sans for headings and controls. Source Serif is reserved for the book covers.

Library: title and ready-to-read count → two large cover-based subject entries → compact live-download strip → browse action.

Subjects: clear availability filter → compact catalogue rows with sizes and selection → selected total and download button.

Downloads: a progress dial beside the current subject → explicit pause/resume → queue → completed items.

Settings and storage: concise sheets, with the same behavior as Shortlist A.

## Critique

A blue recolor of A would not be a useful alternative. This design moves reading ahead of the map, replaces the map illustration with larger book covers, changes the typographic voice, uses a list instead of subject tiles, and makes current download status compact in the library. Blue identifies actions and progress; the cover colors identify content. No ornamental statistics, profile/login, fabricated AI or global search are introduced.

## Interactive behavior

Switch screens, select subjects, filter saved subjects, add selected subjects to the queue, pause/resume, open a subject, change Wi-Fi/sharing settings, or inspect storage. The same sample state is shared across views: Food and Computing are ready, India Map is at69%, Repair is selected. No actual downloads occur.
